# Online Furniture Store 🛋️🛒

Welcome to the Online Furniture Store project! This is an e-commerce platform that allows customers to browse, purchase, and manage their furniture shopping experience. It includes a shopping cart, client profile management, and local storage functionality.

## Project Overview 🎯

The Online Furniture Store is a fully functional e-commerce website where users can:

- Browse a variety of furniture products 🛋️
- Add items to their shopping cart 🛒
- Delete items from the cart if necessary ❌
- Manage their profile, including changing the avatar 📸
- Save their shopping cart information and profile data in Local Storage for convenience and continuity

## Contributors 🤝

This project was developed as part of a group collaboration, where each team member contributed to different parts of the project, from design implementation to functionality.

## Technologies Used 🛠️

The project utilizes the following technologies:

- HTML5 for structuring the web pages
- CSS3 for styling and making the site visually appealing
- JavaScript for managing cart functionality, profile settings, and Local Storage
- Local Storage for saving cart and user profile information
- Figma was used for the design mockups of the website

## Features 🚀

- **Interactive Shopping Cart:** Users can add products, view cart details, and delete items as needed
- **Profile Management:** Clients can create a profile, update their avatar, and save changes to their Local Storage for future visits
- **Responsive Design:** The site is mobile-friendly and responsive, ensuring an optimal experience across devices
- **Local Storage:** User cart information and profile details are stored locally, so users can come back to their cart and profile even after closing the browser

## Setup Instructions 🔧

To run the project locally on your machine, follow these steps:

### 1. Clone the repository

Clone the repository to your local machine using Git:

```bash
git clone https://github.com/your-username/online-furniture-store.git
```

### 2. Navigate to the project directory

Change into the project folder:

```bash
cd online-furniture-store
```

### 3. Open the index.html file

Open the `index.html` file in your preferred web browser to view the website.
